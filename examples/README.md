# Example documents

## `contributor-covenant-2.1.md`

Contributor Covenant v2.1, by the Contributor Covenant authors, from
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Licensed **CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/), unlike
the rest of this repository, which is MIT.

**Changes made to the original:** the reporting-contact placeholder
`[INSERT CONTACT METHOD]` was replaced with `conduct@example.org`, so the
document reads as a rulebook someone actually deployed. Nothing else was
altered — the text is kept byte-faithful on purpose, because it is the thing
being measured, and a note added to the file itself would become another
segment for the tool to ablate.

It is here as a test fixture. It is not this project's own code of conduct.
